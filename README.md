# TicTacToe (Java, Netty, Maven)

Консольная игра «Крестики-нолики» на Java. Текущая рабочая версия — локальный
мультиплеер (два игрока на одном устройстве). Сетевой режим на Netty —
в разработке.

## Запуск
0. Убедитесь, что у вас установлен git и maven.
Команды: git --version и mvn --version
Установка для Ubuntu, если не установлено: sudo apt install git maven
2. Откройте терминал и скопируйте архив в любую удобную директорию: git clone https://github.com/KaiRev0/TicTacToe
3. После копирования перейдите в папку проекта: cd TicTacToe/
4. Выполните: mvn clean compile
5. Выполните: mvn exec:java -Dexec.mainClass="org.kairev0.App"
6. Если всё сделано верно и не было ошибок, то программа должна запуститься с приветственного сообщения

## Что работает
- Локальная игра на одном устройстве, полный игровой цикл, 3 раунда, определение победителя.
- Аккаунты: создание, авторизация по логину/паролю, сохранение в файл и загрузка обратно.
- Система очков и статистики (победы/поражения/KD)
- Клиент-серверный обмен сообщениями на Netty (базовый).
- Простые тесты логики определения победителя.

## В планах

- Общая игровая сессия для двух сетевых клиентов
- Синхронизация состояния игрового поля
- Очередь ожидания и случайный подбор соперника
- Повторная игра без разрыва соединения
- Улучшение хранения данных и тестового покрытия
- Веб интерфейс

## Структура
- `Models` — Player, Game, Id
- `Services` — DataService (файлы), GameService (логика), GameServiceOnline
- `Server` — ServerMain, MyServerHandler (Netty)
- `Client` — ClientMain
- `Utils` — утилиты

## Реализовано

- Игра двух игроков на одном устройстве
- Игровое поле 3×3
- Проверка допустимости ходов
- Определение победителя
- Игра серией раундов
- Профиль игрока и игровая статистика
- Локальное сохранение данных игроков в файл
